# Closed-alpha tester guide

Use only the test identity and test data assigned for the isolated pilot. Never send a password, recovery token or invitation token in a feedback report.

## Planned synthetic model

- Family Alpha: Owner and Member;
- Family Beta: Owner, Admin and Member;
- total: two to five testers, with a multi-Family membership only where the switch scenario requires it.

## Test script

1. Create an account during the controlled registration window.
2. Sign in and confirm the new Family name.
3. Sign out and sign in again.
4. Invite another assigned tester and have that person accept the invitation through the approved channel.
5. Create a synthetic recurring bill.
6. Edit it and confirm the change.
7. Mark one month paid and confirm its status.
8. Delete only the synthetic test bill after confirmation.
9. Request password recovery and follow the approved test-delivery process.
10. If assigned to both Families, switch Family and confirm that the previous Family's data disappears.
11. Repeat the main flow on desktop and mobile.
12. Report unexpected behavior using the template below.
